# 首版算法路线与验证协议

本版本依据当前聊天确认的 EEGNet、注意力多尺度 CNN、知识蒸馏方向，以及直播答疑参数构建。此前 ChatGPT 助手正文未能从引用恢复，所以这里明确列出首版实现选择，不声称复原了不可见的具体层数和超参数。

## 研究问题

以 250 Hz、CP3/CPZ/CP4/PO3/POZ/PO4 六通道、8–15 Hz 对应八类为当前工作参数。主要目标是识别准确率，同时记录参数量、文件大小和单段模型推理时延。比赛本身允许使用整段数据，因此短窗口和轻量化属于本项目的工程目标；不能让其替代对准确率的验证。

首轮固定 1 秒窗口。公开数据保留原始刺激频率、通道与受试者来源。尚未取得今年正式数据格式和确切电极布局，当前接口只覆盖已知样例以及 BETA 原始 MAT 文件。

## 算法组件及理由

### 1. CCA / FBCCA 基线

为每个频率构造前三个谐波的正余弦参考矩阵。对信号和参考分别去均值、以 SVD 获取非退化列空间基，再计算两个基乘积的最大奇异值，得到第一典型相关系数。CCA 分数为相关系数平方。

滤波器组 CCA 增加 6–90、14–90、22–90 Hz 三组子带，并按 `(子带编号)^(-1.25)+0.25` 加权相关系数平方。这是首版固定实现选择；没有根据 D2 测试准确率搜索滤波器参数。常量/秩亏输入显式处理。

该基线不需要大量带标签样本，有助于检验网络是否真正利用了 SSVEP 频率信息。所有分类计算由本项目实现，未调用第三方成品脑电分类器。

### 2. 多尺度注意力 CNN 教师

并行 15/31/63 点时间卷积学习不同时间尺度，再用按特征组的全电极空间卷积学习六通道组合。拼接后用 1×1 卷积融合，再用通道注意力、时间卷积和自适应池化得到时间特征。

另提取 8 个目标 × 3 个谐波的相对对数谱能量，与时间特征拼接形成 128 维教师表示。相对谱能量帮助网络利用已知频率结构，而非依靠波形振幅或受试者差异作判断。

这里的“多尺度注意力 CNN”是原创建模组件，不声称是某篇未指定 AttentCNN 论文的原样复现；后续如取得原对话的精确模型定义，可据此对齐。

### 3. EEGNet 学生

沿用 EEGNet 的时间卷积 → 深度空间卷积 → 可分离时间卷积结构思想，并增加轻量通道注意力、固定维度自适应池化和谐波谱特征。学生表示为 32 维。

这属于 EEGNet 的 SSVEP 适配版本，而非标准原论文精确复现。直接训练学生和蒸馏学生使用相同初始权重种子，以降低初始化差异对比较的影响。

### 4. 知识蒸馏

`损失 = (1−α) × 真实标签交叉熵 + α × T² × KL(教师软分布 || 学生软分布)`。

首轮固定 T=3、α=0.5；教师进入推理状态并冻结参数，软目标不反向传播。训练中教师与学生接收同一输入扰动。首版先验证输出分布蒸馏；尚未加入特征蒸馏、伪标签、自训练或量化，避免把多个变化同时归因于蒸馏。

必须比较：教师、无蒸馏学生、蒸馏学生以及 CCA/FBCCA。若教师在验证集不强于学生或蒸馏没有收益，结果报告会明确记录，而不会把蒸馏设为必然更优的部署方案。

### 5. 每类一个参考样本的校准

根据直播说明模拟每组每类一个带标签原始试次。基线采用参考样本的谱模板余弦相似度；神经网络采用冻结特征的类别原型相似度。支持集均值由八个参考计算，未知标签查询数据不参与拟合。将标准化的原始分类分数与模板/原型分数融合，融合权重只在验证支持集/查询集选择。

支持试次从查询评分中剔除。报告分别给出全部测试的无校准结果、查询子集无校准结果和同一查询子集校准结果；不能拿不同分母的准确率直接比较校准收益。

真实使用时必须显式提供赛方标定参考文件，推理接口不读取查询文件的 `stim_id`。在当前离线实验中，模拟支持集借助数据真值每类取第一段，这只是验证协议，不表示比赛推理时可查看未知真值。

## 数据及防泄漏

- D1 48 段按原始试次分为训练 32 段、验证 16 段（每类留两段），D2 48 段作为锁定测试文件。文件与受试者关系未知，因此只能称文件留出验证。
- BETA 首轮最多取已通过下载校验的 20 人，并冻结本轮文件清单和 SHA-256。按受试者约 60/20/20 划分训练/验证/测试，不能跨集合混入同一受试者。
- BETA 去掉 0.5 秒预刺激及 0.5 秒后刺激区段，并额外扣除 0.14 秒视觉延迟。0.14 秒是当前公开数据实验选择，不赋给赛方数据。以 `suppl_info.freqs` 查找八个匹配频率，电极按名称查找。
- 先划分原始试次，再切窗。训练窗步长 0.5 秒；验证和测试各原始试次取首个 1 秒窗，以使评分单位保持原始试次。
- 当前预处理为四阶 6–90 Hz 带通与每段每电极标准化，不拟合混合人群统计。训练采样对赛方/公开数据来源赋相同总权重，降低公开数据数量压倒样例的影响。
- 默认零相位滤波读取完整原始试次，再切短窗，是离线比赛流程。配置另支持因果滤波实验；默认结果和纯模型时延不能称为端到端实时表现。
- Nakanishi 通道和刺激频率不匹配本轮八类，保留为独立补充数据，首轮不强行并入训练。
- 在验证集选最优 epoch、校准权重及默认算法；测试结果只报告，不能用于本轮部署算法选择。

## 运行与产物

实际训练环境为 `.venv_gpu`，基于本机 `eegconformer` 的 Python 3.10.21、PyTorch 1.12.1、NumPy 1.23.5、SciPy 1.10.1，通过 system-site-packages 复用已安装依赖；原环境未被修改。GPU FFT、卷积及反向传播已实际验证。新组件下载环境 `.venv` 未完成，不用于首轮训练。推理仅加载本项目自行生成的可信权重；新 PyTorch 可用时启用 weights_only 加载。

```powershell
.\.venv_gpu\Scripts\python.exe -m unittest discover -s tests -v
.\.venv_gpu\Scripts\python.exe -m ssvep.experiment --run v1-initial
```

可用 `--epochs` 和 `--max-beta-subjects` 执行流程检查，但检查结果不视为充分训练。配置为 `configs/experiment_v1.json`。实验名必须唯一，避免覆盖已有结果。

每轮保存：解析后的配置、来源指纹、原始试次划分、训练曲线、最优模型权重、逐试次预测、混淆矩阵、校准支持与查询索引、参数量、模型推理时延、验证集选择的部署策略和完成标志。

推理入口：

```powershell
.\.venv_gpu\Scripts\python.exe -m ssvep.inference --run runs/v1-initial --input query.npz --output predictions.csv
```

输入应为 `X[试次,6,时间]`、`channels`、`sampling_rate_hz`、`task_id`。参考文件另含 `stim_id`，通过 `--support` 显式提供，并与查询保持全局唯一试次编号。当前生成 CSV 仅为开发输出；正式结果文件必须使用本队 UID 关联的官方模板。
