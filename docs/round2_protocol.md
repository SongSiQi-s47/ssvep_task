# 第二轮：现有数据只验证，独立来源训练

历史协议：用户随后已明确 D1/D2 只验证、BETA 可按受试者隔离训练。最新有效协议见 `round2_beta_protocol.md`；本文保留此前 Benchmark 先导实验的依据，不再代表当前数据角色。

依据用户 2026-10-15 的新要求“当前数据集仅做验证”，先采用保守范围：D1/D2、当前 BETA、Nakanishi 均不用于本轮训练或校准。已询问用户具体范围，在回复前不放宽限制。新训练来源 Benchmark 不属于上述已获取三套数据，因此无需改变该保守约束。

## 数据用途

- **训练来源：** 新获取 Wang2016/Tsinghua Benchmark，MOABB 维护的 Zenodo 原始 MAT 镜像：https://zenodo.org/records/14865172 。仅下载原始数据与元信息，分类算法仍由项目实现。
- **首轮规模：** 预先选定 S1、S7、S14、S21、S28、S35 六名受试者，覆盖编号范围而非按准确率选择。数据约 636 MB，六个 MAT 文件均须通过发布方 MD5 后才开始训练。这是小规模先导实验，不是全量 35 人结果。
- **内部开发：** 六名受试者按固定 split_seed=2026 分为四人训练、一人开发验证、一人内部留出。三次模型初始化种子为 2026/2027/2028，人员划分保持不变。
- **外部历史数据验证：** D1/D2 全部 96 段、当前已校验 BETA 全部匹配八类的试次，只在本轮所有模型冻结后计算结果。不进行伪标签、蒸馏输入、支持集校准或全体统计拟合。Nakanishi 频率与八类任务不匹配，继续保留，不强行给出八类分数。
- **不复用 v1 权重：** 所有模型从新初始化开始。v1 的训练已经看过 D1/BETA，不能拿 v1 权重宣称实现新协议。
- **重复检查：** 保存训练来源和保留验证来源的 SHA-256，拒绝跨用途的字节相同文件；同一训练来源内部按受试者隔离，先划分再切窗。来源间受试者身份未知，不能据文件不同宣称人群身份完全互斥。
- D1/D2 过去的结果已被反复查看，即使本轮完全不训练它们，也只能称历史数据验证，不能重新宣称它们是从未触碰的盲测集。

## 新教师与对照

新增频率共享评分教师，包含三个谱尺度的谐波/背景功率比、通道注意力和各候选频率共用的非线性评分器。固定谐波先验作为残差，避免大模型主要记住源数据的相位、波形或类别偏置。该教师为本项目新实现，不宣称复现特定论文。

每个种子分别比较：FBCCA 固定基线、频率共享教师、直接训练的 EEGNet 适配学生。仅当教师在独立 Benchmark 开发受试者上的准确率严格高于学生时，才运行输出分布蒸馏，首轮固定 α=0.25、T=2。门槛失败时如实记录，不能以跳过种子的子集冒充完整三种子的蒸馏结论。

窗口固定 1 秒，训练步长 0.5 秒。Benchmark 从刺激前 0.5 秒之后再扣 0.14 秒，结束于刺激结束；采样率 250 Hz、电极按位置表名称选择。八个整数目标为 MAT 目标维前八项，依据 MOABB Wang2016 维护者事件映射；原镜像 Readme 说明其余目标频率/相位另由 Freq_Phase.mat 保存，该文件尚未取回，因此只采用已有明确索引依据的整数目标，不推断相位。

元信息依据：https://github.com/NeuroTechX/moabb/blob/develop/moabb/datasets/ssvep_wang.py 。使用这里的采集/索引信息，未调用其分类器。

开发受试者用于早停、教师门槛和默认算法选择；保留验证数据只用于最终报告，不参与这些选择。每个种子独立保存部署策略，明确关闭支持集校准。

## 运行与状态

`Start-Round2.ps1` 启动单次后台流水线：下载与校验 → 三种子训练与开发选择 → 全部模型冻结 → 历史数据验证。没有创建定时任务或循环监控。

状态文件：`logs/round2.pipeline.json`；完整输出：`logs/round2.stdout.log`、`logs/round2.stderr.log`。下载进度为 `logs/benchmark_download_status.json`。电脑需要保持运行及联网。

结果目录：`runs/v2-independent-benchmark/`；只有同时存在本轮 `completed.json` 且流水线 stage 为 complete，才代表训练与验证完成。下载/训练进行时不能填入预测准确率。
