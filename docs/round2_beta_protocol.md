# 第二轮确认协议：BETA 训练，D1/D2 仅验证

用户已明确“赛方 D1/D2 仅用于验证；公开 BETA 可训练，按受试者隔离”。本文件取代此前保守口径的当前实验说明；旧 Benchmark 实验及其配置、结果不改写。

## 数据角色

使用已通过发布方校验的 24 名 BETA，固定 split_seed=2026，按受试者划分为 14 人训练（448 个原始试次）、5 人开发验证（160 试次）、5 人内部测试（160 试次）。各集合受试者无交集，同一原始试次的窗口不跨集合。具体姓名匿名编号见运行目录 `subject_roles.json`。

D1 和 D2 共 96 试次全部保留评分，模型训练过程中不读取其信号；不使用其标签进行权重更新、蒸馏、原型/模板校准、早停或模型选择。所有种子的模型冻结后才进行评分。历史上已看过 D1/D2 的结果，因此不将其称作全新盲测集。

公开 BETA 文件清单、数据指纹和人员划分在本轮冻结。没有使用 v1 或 Benchmark 先导实验权重。Nakanishi 频率不匹配当前八类，不纳入本轮八类训练或评价。

## 模型与验证

1. 频率共享谱评分/电极注意力教师（26,661 参数），直接训练 EEGNet 适配学生（6,484 参数），固定一秒窗口，三个初始化种子 2026/2027/2028。切分在三个种子间保持一致。
2. 教师门槛：教师必须在 BETA 开发受试者上严格优于学生，才可做神经教师蒸馏。三次 CNN 教师均未达门槛，均跳过该项；不是蒸馏训练失败或零准确率。
3. 续实验使用 FBCCA 算法教师。仅用 BETA 开发集的负对数似然，在预定全局分数倍率 [1,2,4,8,16,32] 中选取软目标尺度。所有 BETA 训练短窗的算法分数与输入一一对应缓存，只有这些训练窗口参与蒸馏。
4. 蒸馏固定温度 T=2，α=0.25；每个蒸馏学生与其直接训练对照使用相同初始化种子。教师软目标对应原始训练窗口，学生接收小幅噪声扰动作为一致性训练；不用 D1/D2 输入生成软目标。
5. 所有早停、教师门槛、默认算法选择只依据 BETA 开发集。D1/D2 及 BETA 内部测试不用于这些选择。

三种子结果应报告均值和标准差，并保留每个种子，不能按 D1/D2 表现选最好种子。种子数量少，不作统计显著性或赛场泛化保证。

默认预处理是离线零相位滤波完整记录后再取一秒窗口。模型时延不包含原始数据采集和预处理，不能当成端到端实时响应。
