# EEGNet 文献、赛题要求与训练路线复核（2026-10-28）

## 依据与边界

- 赛题图片：任务为从 N 组脑电中提取每次 SSVEP 实验片段，预测 0–7 八类，按全部任务的 ACC 排名；算法任务占 60%，技术报告占 40%。图片没有指定采样率、物理频率、通道、窗长或训练轮数。
- 用户提供的直播答疑原文 `C:/Users/lenovo/Desktop/脑机接口及应急机器人/脑电算法赛道直播答疑_原文行号对照.txt`：原文 139–163 行说八类 0–7、通常 250 Hz、8–15 Hz 的顺序映射；601–631、2421–2431 行说正式数据每类有一个带标签参考，其余无标签，但“每组”范围需要见正式数据；711–735 行允许使用提供的整段；885–893 行明确允许赛方提供的公开数据预训练；原文 941 行提示频率配置可能变化。这是答疑转写，不代替正式数据元信息。
- EEGNet 原论文：Lawhern 等，*EEGNet: A Compact Convolutional Network for EEG-based Brain-Computer Interfaces*，arXiv:1611.08024v4，2018，https://arxiv.org/abs/1611.08024 及 https://arxiv.org/pdf/1611.08024 。论文研究 P300、ERN、MRCP、SMR，未在该文评估本赛题的八类 SSVEP。论文架构的主要顺序是时域卷积、逐时域滤波器的深度空间卷积、可分离时域卷积、池化和分类器；跨受试者实验使用 dropout 0.25。论文使用 Adam、交叉熵、最多 500 epoch，并根据最低验证损失保存权重。这些是论文条件，不能直接移植为本赛题最佳参数。

## 原论文与当前网络的准确关系

| 项目 | 原论文 EEGNet | 本仓库 `EEGNetStudent` |
|---|---|---|
| 主要卷积 | 时域卷积 → 深度空间卷积 → 深度可分离时域卷积 | 同样的主干顺序 |
| 采样率与卷积核 | 表 2 以 128 Hz 输入举例，时域核 64 点，约半秒；第二核 16 点，经过首次池化后约半秒 | BETA 250 Hz，核 63 点约 0.25 秒；第二核 15 点在首次 4 倍池化后约 0.24 秒。不是原论文的时间尺度 |
| 空间卷积 | 每个时域滤波器分别学习空间滤波器，论文给出最大范数约束 | 分组卷积保留这个结构，但没有对应的最大范数约束 |
| 池化与头部 | 4 倍、8 倍平均池化，展平后直接分类 | 两次均为 4 倍池化，再自适应池化；追加通道注意力、固定频率谐波特征和 32 维全连接层 |
| 训练/选择 | Adam、交叉熵、最多 500 epoch，按验证损失停止与选权重 | AdamW、交叉熵、50 epoch，按开发受试者宏平均 ACC 选最早最高权重 |

因此现有模型应称 **EEGNet 启发的 SSVEP 改造版**，不可称“原论文 EEGNet 复现”。论文没有证明该网络在本赛题上优于 FBCCA。要测“原版 EEGNet”应另立固定配置的对照实验，明确是否按 250 Hz 缩放卷积核与池化时间尺度，不能将这个对照结果追溯为既有 v5–v7 成绩。

## 当前路线与赛题目标的对照

| 环节 | 当前状态 | 判断 |
|---|---|---|
| 数据角色 | BETA 按受试者训练/开发/确认；D1/D2 仅冻结后验证 | 保留。D1/D2 各 48 段且已多次被查看，不能参与训练、早停、参数/种子挑选、伪标签或支持集校准 |
| 目标类别 | BETA 从 MAT 的实际频率元信息找 8–15 Hz；D1/D2 用 0–7 标签核对 | 对旧样例可复现。正式映射须从新元信息核验，不能只依直播转写 |
| 时间对齐 | BETA 从刺激前 0.5 秒后再加 0.14 秒响应延迟取首窗；D1/D2 从段首取窗 | 这是跨来源差异及泛化风险，尚无证据认定为成绩差距的唯一原因。正式 onset/延迟未确认前不能默默套 BETA 偏移 |
| 观察长度 | 固定首 375 点，即 1.5 秒；先裁剪再做零相位滤波和逐通道标准化 | 与 v5–v7 推理入口一致，但图片与答疑均未要求只用 1.5 秒。整段方案应在外部开发数据上另立实验，不根据 D1/D2 的分数选择 |
| 学习模型 | `EEGNetStudent`，26 名 BETA 训练者，50 epoch、batch 64、每 epoch 1408 窗口、3 种子 | 已实际训练并有冻结记录。增加训练人员和更新量未带来跨确认组稳定优势；停止单纯加 epoch/种子追分 |
| 基线 | 固定 FBCCA，无训练参数 | 保留为清晰的物理频率基线和当前可复核输出；与改造 EEGNet 在相同原始试次及预处理下比较 |
| 主要指标 | 旧报告多用受试者宏平均 ACC，按人展示 | 赛题主指标应是全部待预测原始试次的总体 ACC；开发阶段同时报告逐受试者成绩。已用的 BETA 确认每人 32 段，宏平均与总体 ACC 数值相同；正式组数或试次数不等时不再相同 |
| 参考样本 | 现有 v5–v7 未使用每类一个带标签的校准信息 | 单列未来分支：先在 BETA 以完整 block 隔离 support/query，模拟每类仅一个参考；只有正式元信息界定“每组”的范围后，才实现赛方适配 |
| 输出与报告 | 已有开发 CSV；正式标准结果模板未到手 | 需适配赛方原模板和新文件格式；技术报告应解释数据、对齐、模型结构、基线、逐试次 ACC、失败分支与复现流程 |

## 推荐的下一轮总体路线

1. **先冻结赛题接口与角色。** 以新数据说明核验采样率、通道、类别频率、试次边界、参考样本的作用域和标准结果文件。将赛方提供的带标签参考与未知标签 query 分开；D1/D2 保持只验证。外部 BETA 与赛方公开参考数据的训练许可分别记录。
2. **做输入和评估审计。** 按原始试次和受试者划分后才切窗；任何来自同一原始试次的窗口不跨组。所有方法使用相同可观察原始片段，先裁剪再预处理。报告总体 ACC、逐受试者 ACC、混淆矩阵、三个种子的全部结果，不能只选最好的种子。新方法试验需要预留此前未参与选择的人员。
3. **保留固定 FBCCA，与两个神经对照并列。** 一项是当前 SSVEP 改造版；另一项若要声称复现文献，按论文结构单独实现/记录“原论文 EEGNet 的 250 Hz 适配版”，保持和当前模型相同的受试者划分、窗长及训练预算，并明确论文头部/卷积核与改造点。先在训练与开发集确定有限候选，再对未用受试者一次性确认。
4. **优先检验更贴近赛题的时间范围与校准假设。** 直播答疑允许整段，也称正式每类一个参考；先在 BETA 按 block 做支持集/查询集模拟，比较无校准 FBCCA、单参考模板、EEGNet 对照。窗长与 BETA 延迟只能在外部开发集上选择，不能从 D1/D2 反复试错。不同公开数据集的匿名受试者重合需审计。
5. **设停止和交付标准。** 若新神经模型在隔离确认组的总体 ACC 不稳定超越 FBCCA，则保持 FBCCA 作为性能基线，神经方案如需用于提交须单独证明符合最新版规则。若确认收益成立，再做速度、模型大小和蒸馏；否则不应先扩复杂教师。拿到标准结果文件后，用无标签推理路径逐段填入并检查行数、标识、类别范围、原文件名和模板结构。

## 当前结论

v5 的新 BETA 五人：14 人训练改造 EEGNet 46.67%，固定 FBCCA 52.50%。v6 的另一组新 BETA 五人：26 人 EEGNet 55.00%，FBCCA 53.75%；仅小幅领先。v7 的第三组新 BETA 五人：增加更新量 EEGNet 45.21%，FBCCA 72.50%。三个确认组难度不同，不能把其中一组的领先概括为稳定提升。D1/D2 保持历史样例验证用途，不因其分数调整后续训练路线。

此次仅复核路线与文献，没有执行新训练、改变数据角色或重选权重。
