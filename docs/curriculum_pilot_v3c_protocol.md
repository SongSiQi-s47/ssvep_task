# 第三阶段最终小试验：长窗到短窗课程训练

前两类小试验未获得双种子一致改善。本组固定一个新假设，不进行窗口长度/切换时刻网格搜索：先用更长观察窗学习，再适配目标一秒窗口。

沿用六名 BETA 训练受试者、三名筛选开发受试者、两名保留确认开发受试者。D1/D2 与 BETA 内部测试五人仍完全不读取。

比较纯交叉熵的两个学生：

- 基线：50 epoch 全部使用一秒窗口。
- 课程：前 25 epoch 使用 1.5 秒，后 25 epoch 使用一秒。筛选和确认始终使用一秒输入。

每 epoch 均为 768 样本，batch=64，共 600 次梯度更新。网络、优化器、学习率、初始化和原试次的抽样权重不变。长窗的起点按原枚举窗相对位置映射到有效范围，不因长窗改变某个人贡献的样本数量；不补零、不跨试次拼接。

虽然更新次数相同，课程组前半程输入点数较多，因此不是严格等 FLOPs/等运行时间实验。保存实际训练时长供评估额外成本。

筛选种子 2026/2027；仍要求两者均不退步且平均提高至少 3 个百分点。通过后才用新种子 2028 训练两组，再读取两名保留开发受试者，要求平均提高至少 2 个百分点、单人下降不超过 3.125 个百分点。

这是本阶段最后一个训练假设。若失败则结束本阶段，不再根据同一筛选开发集追加参数搜索。所有阴性结果保留，不把一次最佳种子当作方向确认。

配置为 `configs/pilot_curriculum_v3c.json`，结果为 `runs/v3c-long-to-short-curriculum/`。
