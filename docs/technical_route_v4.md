# 技术路线修订 v4（2026-10-16）

状态：路线决策与下一轮验证协议，尚未执行新实验；不代表新模型已经提升。

## 核心决定

主线改为“评估口径修正 → FBCCA 物理频率基线 → 小型可学习评分融合 → 有条件蒸馏”。EEGNet 保留为轻量神经候选；多尺度注意力 CNN 教师退出近期主线。目标优先级为跨受试者可靠性、准确率、端到端耗时，最后才是进一步压缩。

这不是否定神经网络或知识蒸馏，而是取消必须由复杂教师带学生的架构前提。当前学生仅 6,484 参数，继续压缩不是已经证实的主要瓶颈。FBCCA 是现有 BETA 开发集选出的默认算法，不因 D1/D2 的历史分数重新选模型。

## 决策依据与局限

第二轮 BETA 开发集 FBCCA 为 63.75%，最佳已导出蒸馏神经候选为 61.875%。内部测试上，直接学生三种子均值 60.42%，算法蒸馏 61.88%，FBCCA 58.13%；因此不能说 FBCCA 在所有数据上都更好。CNN 教师开发表现弱于学生，神经教师蒸馏被预设规则跳过。

历史 D1/D2 验证为 FBCCA 61.46%、直接学生均值 54.86%、蒸馏学生均值 56.25%。这些数字只能提示迁移风险，不能用来调整融合权重、窗长或挑种子；D1/D2 已有历史暴露，不是盲测。

第三阶段 16 次小训练中，随机切窗、相位/幅值增强、增强加余弦调度、跨受试者对比损失、长到短课程均未过筛。对齐损失平均仅 +0.52 个百分点且两种子方向不一致。停止扩大这五条配置，不把小样本阴性结果泛化成方法普遍无效。

依据：docs/round2_beta_results.md、docs/training_pilot_v3_results.md。

## 必须先修正的评估口径

当前 preprocess 对完整原始试次离线滤波并按全试次归一化，再取首个一秒。它没有使用其他试次或标签，但使用了窗口结束之后的信号；因此“输入一秒”不等于“只观察了一秒”，GPU 约一毫秒也只是网络计算耗时。

下一轮同时保留两个明确模式：

1. 离线主模式：只提供指定长度的原始片段，再在该片段内完成滤波与归一化。所有算法收到相同片段；计入边界效应，记录起点与长度。先比较 1.0 秒与 1.5 秒，BETA 已有短记录也能覆盖，不补零延长。正式比赛允许使用整段时，可另做整段模式，不能把长窗收益归因于模型结构。
2. 流式附加模式：因果滤波，显式维护状态，仅使用当前及过去样本计算归一化；按真实起点计入暖启动和采样等待。只有需要在线部署时才进入该分支，不能直接拿旧离线权重宣称在线达标。

250 Hz、六通道、8–15 Hz 沿用当前备赛映射；正式元信息仍需核对。BETA 的 0.14 秒延迟设定不直接迁移为赛方已确认参数。

## 修订后的算法结构

**A：无校准 FBCCA 主基线。** 保留当前固定滤波器组和谐波设置，先做口径一致的窗口对照，不进行大范围参数搜索。记录分受试者准确率、混淆矩阵、分数间隔及预处理加推理耗时。

**B：原 EEGNet 直接监督候选。** 沿用枚举切窗、交叉熵、固定学习率等原有效基线；用修正后的输入流程从头训练。先核实增加到现有 14 名训练受试者的效果，再考虑获取更多受试者；更多重叠窗口不等于更多独立样本。

**C：小型评分融合候选，先于新大教师。** 输入每个候选频率的 FBCCA 子带分数、相对谐波能量等，采用候选频率间共享的线性评分器，并保留固定 FBCCA 对照。标准化统计和权重仅由 BETA 训练受试者拟合。先只验证一个预注册方案，避免同时搜索复杂网络、融合比例与增强。该方向是待检验假设，当前尚无提升证据。

神经预测与 FBCCA 的错误互补性只在公开开发数据中诊断；只有互补明确、简单融合也过门槛，才增加神经融合支路。报告的“理想择优”只能作为诊断上界，不能作为可部署结果。

**D：知识蒸馏改为有条件压缩。** 仅当教师在受试者隔离的公开确认中稳定优于直接学生，并且测得运行成本值得压缩时启动。软目标限 BETA 训练数据。学生需同时满足准确率非劣和端到端效率收益，才替代较强教师；不能因模型叫“蒸馏”而直接晋级。具体非劣容忍值与时延目标必须在该阶段运行前按部署设备冻结。

**E：参考样本分支单列。** 如未来赛方明确提供每类一个参考样本，先在 BETA 用一 block 作 support、其余独立 block 作 query 模拟，按受试者划分训练/开发；不可把同一试次切片分给 support/query。先研究参考模板相关与无校准分数融合。标准 TRCA 依赖跨试次重复性，不能把单个参考样本切窗冒充多个独立重复试次。该分支不自动改变 D1/D2 禁止校准的现行约束。

## 下一轮有限实验与晋级规则

顺序固定，前一项失败时先解释原因，不同时铺开全部候选。

1. 数据与预处理审计：核对已有 BETA 元信息、裁剪长度、频率/通道顺序；合成信号验证边界和谐波响应；不给 D1/D2 做调参诊断。输出新旧流程差异，所有旧数字标记旧口径。
2. 窗长试验：仅 FBCCA、1.0/1.5 秒、新流程，在已有公开开发集比较。选定一个主窗长后冻结，再进入模型试验；它是开发决策，不是独立效果证明。
3. 算法筛选：沿用第三阶段六名训练、三名筛选开发受试者，比较固定 FBCCA、从头训练 EEGNet、单一共享线性评分候选。训练模型使用种子 2026/2027，公平固定预算；报告算法训练成本差异。主指标为受试者宏平均准确率，原始试次为预测单位。
4. 筛选门槛：候选相对同窗长 FBCCA 与直接学生两者中较强者，两种子均不退步、平均至少 +3 个百分点，方可进入确认；这是一条实用筛选规则，不是显著性检验。最多一个新评分方案，无候选过线则停止，不降低门槛。
5. 通过后才用原 14 名训练受试者与三个种子扩大验证；仍以 S6/S20/S51 选 checkpoint，S13/S23 仅作本轮确认，平均增益至少 +2 个百分点且每名确认受试者下降不超过 3.125 个百分点。这些受试者历史上均已用于开发，不能叫全新盲测。
6. 更强的泛化证据需新获取、此前未查看的 BETA 受试者。下载前冻结名单分配规则，将新增训练人员与新增最终测试人员分开，绝不把全部新增数据用于训练后再称其为测试。已有五名内部留出已在第二轮评分，保持角色但称历史留出复核；新测试仅在完整方案冻结后一次性评分。

D1/D2 仍仅在阶段方案完全冻结后做外部样例验证，不用于训练、软目标、早停、模型选择或参考样本校准。下一轮上述小筛选不读取 D1/D2，也不重复读取历史内部留出。公开 Benchmark 暂作后续迁移验证候选，不混入本轮训练；不同数据集匿名受试者是否重合不能仅靠文件名保证。

统计报告按受试者展示配对差值，不把重叠窗口当独立样本。少量受试者下不作“统计显著提升”断言。运行成本分别报告信号等待、预处理、算法推理和总耗时，注明硬件、batch=1、预热与重复次数。

## 当前落地状态

本次仅修订路线和验证计划，未启动新训练、未读取原始验证信号、未替换任何部署模型或数据用途策略。现有 FBCCA 默认算法与 EEGNet 导出候选继续保留。下一次执行从输入范围审计和固定 FBCCA 窗长对照开始。
