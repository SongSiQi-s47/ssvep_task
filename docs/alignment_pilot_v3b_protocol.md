# 第三阶段补充：跨受试者类别特征对齐

首个 30 epoch、四方法、两种子小试验全部候选均未达到预设门槛，原始结果保留，未修改门槛或打开确认开发数据。补充试验检验另一个问题：同一刺激类别来自不同受试者时，特征表示是否需要额外对齐。

本试验仍只使用六个原训练受试者和三个筛选开发受试者；D1/D2 与 BETA 内部测试数据不读取。两个确认开发受试者继续保留，只有筛选成功才使用。

## 方法

在原交叉熵上增加权重 0.1 的跨受试者监督对比损失，温度 0.2：同类别、不同受试者为正对，不同类别为负对；同类别、同受试者既不作正对也不作负对；无正对的锚点不贡献损失。

采用当前网络已有的 32 维表示，不增加网络层。对比损失只在训练批次使用，不增加部署模型参数。

参考监督对比学习的原始思路：https://arxiv.org/abs/2004.11362 。跨受试者正对及排除同类同人的规则是本项目改造，并非声称复现原论文全部实验。

## 公平对照

两组分别为纯交叉熵基线和交叉熵+对比损失，均使用原枚举切窗、相同采样器、相同弱噪声、相同初始化种子、固定学习率和相同优化器。

两组均跑 50 epoch，每 epoch 768 样本，共 600 次梯度更新。不能将本组 50 epoch 与上个小试验 30 epoch 的数值直接相减后归因于对比损失。

仅测试这一个固定的权重/温度组合，不根据开发结果追加网格搜索。两种子筛选和第三种子+两人确认门槛沿用原设定。确认失败也不改阈值；本阶段结果只用于判断是否值得进入完整受试者实验。

配置为 `configs/pilot_alignment_v3b.json`，结果为 `runs/v3b-cross-subject-alignment/`。原随机裁剪/增强试验在 `runs/v3-training-method-pilot/`，独立保存。
