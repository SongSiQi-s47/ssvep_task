# v6 扩大训练：预分析与输入兼容性

## 先验检查

在继续训练前，对赛方 D1/D2 原始 CSV 运行 `python -m scripts.smoke_competition_v6`。两份文件各有 48 个原始试次、八类各六段、每段六通道 × 1000 点；按冻结的 375 点首窗裁剪和窗口内预处理后，FBCCA 与 v5 EEGNet 分别输出 48 × 8 的有限分数。来源 SHA-256 和形状见 `runs/v6-input-smoke.json`。因此无需调整 D1/D2 文件格式；正式比赛的新格式仍需另行对齐。

## 上轮现象与原因假设

v5 中十四人 EEGNet 在新 BETA 五人上相对六人训练提高 6.46 个百分点，但比 FBCCA 低 5.83 个百分点。逐人相对 FBCCA 只有 2/5 为正；D1 弱、D2 强，说明单一平均值无法代表稳定跨域改进。训练损失持续下降，而不同受试者成绩分散，这与受试者及采集条件差异、短窗信噪比差异相符；现有记录不能把差距唯一归因于网络容量或格式错误。

v5 训练窗口来自 14 名受试者共 448 个原始试次。重叠窗口有利于训练，但不增加独立人员数。因此本轮把训练人员扩到 26 名；模型、1.5 秒首窗、预处理、采样更新预算与三个种子保持不变，使新增人员成为主要变化。开发 checkpoint 仍由 S6/S20/S51 选择。另按冻结的哈希顺序留出五名此前未使用的 BETA 人员；它们和 D1/D2 在所有权重冻结后才评分。D1/D2 仍是已暴露、人数身份不明的小样例，不能用来调参或声称盲测。

## 运行

角色和参数：`configs/expanded_v6.json`。下载指定子集使用 `scripts/download_beta_subset.py`，其大小及发布方 MD5 由仓库的下载清单核查。先 `python -m ssvep.expanded_v6 train`，冻结完成后 `python -m ssvep.expanded_v6 confirm`。运行记录保存在 `runs/v6-expanded-eegnet/`；确认阶段拒绝覆盖已有结果。
